Politique de confidentialité

Ce que nous faisons de votre code

Mise à jour le 12 juillet 2026. Deux traitements distincts, à ne pas confondre.

aucun envoi

Le scan

Vos fichiers sont lus depuis l'API GitHub, analysés en mémoire sur nos serveurs, puis écartés. Rien n'est transmis à un service d'intelligence artificielle. Ce qui est conservé, c'est le rapport : les détections, les chemins, les extraits qu'elles citent.

envoi à OpenAI

Le tri, si vous le déclenchez

Uniquement quand vous cliquez sur le bouton de tri, et uniquement ce qui est nécessaire :

Secrets et .gitignore — la liste des détections déjà produites (titre, chemin, sévérité). Pas votre code.
Qualité et documentation — des extraits de code, limités aux lignes citées par les détections.

Le jeton GitHub

Chiffré au repos, portée en lecture seule, jamais affiché ni journalisé. Supprimé immédiatement à la suppression du compte.

Conservation

Les rapports restent jusqu'à ce que vous les supprimiez. Rien n'expire automatiquement, rien n'est revendu, aucun traceur publicitaire.
